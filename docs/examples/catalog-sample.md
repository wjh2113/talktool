# 分类：导入示例

## 场景：示例场景
副标题：用来验证管理员导入是否正常

### 训练：示例·向领导一分钟汇报

- 压力：低压
- 时长分钟：2
- 用户角色：部门员工
- AI角色：部门主管，会对不清楚的地方追问一句
- 训练目标：结论先行、说清需要配合的人
- 开场白：好，下一个，你说说今天的安排。

#### 场景描述

你在部门早会上有一分钟汇报当天工作。手上有三件事：改客户方案、跟财务对账、面试候选人，其中对账需要同事小王配合。请用结构化方式汇报，并说清需要谁配合什么。

#### 常见误区

- 流水账讲细节超时
- 不说需要谁配合
- 只说做什么不说风险

#### 推荐框架

- prep｜今天三件事，重点是对账需要小王配合。
