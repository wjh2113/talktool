# 谋略库导入格式（谋略 / 谋士 / 智囊团）

管理员在 **我的 → 管理后台 → 场景导入** 上传 `.md` 或 `.zip`，和场景库、表达框架用同一个入口。系统按文件开头的标记（或 `## 谋略：` 这类标题）自动识别是哪一种。

通用规则：

- 每条内容靠 `code` 匹配：已有就更新（「更新或新增」模式），没有就新增；「仅新增」模式下已存在的跳过。
- 导入的内容会标记为「自定义」，以后程序升级时内置内容不会把它覆盖。
- 字段写成 `- 字段：值`（中英文冒号都可以），放在标题下面、各小节（`###`）之前。
- 一个 zip 里可以混放场景库、框架库、谋略、谋士、智囊团文件；同一批里先导谋士、再导智囊团没问题。
- 有问题的字段（不认识的领域、不存在的框架 code）会被忽略，并在导入结果里列出提醒；缺必填项时整批不导入，并提示是哪一条。

示例文件：`docs/examples/strategies-sample.md`、`advisors-sample.md`、`councils-sample.md`。

## 一、谋略

文件第一行：`# talktool-strategies`

```markdown
## 谋略：先礼后兵
- code: xianli_houbing
- 体系: zhanguoce
- 出处: 民间智慧
- 领域: 谈判、为人处世
- 框架: ask_first, trade
- 慎用: 否

### 原文
先礼后兵。

### 白话
先讲道理、给台阶，对方不接再亮底线。

### 怎么做
1. 先私下沟通，给对方留面子
2. 对方不接，再书面亮出底线和时间

### 怎么说
我们先按合作的方式商量；如果实在谈不拢，我这边只能按合同来办了。

### 常见误用
一上来就亮底牌，把商量变成了威胁。
```

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 `## 谋略：名称` | ✓ | 名称最多 30 字 |
| code | ✓ | 小写字母开头，只能有小写字母、数字、下划线，2–40 位，全库唯一 |
| 体系 | ✓ | 已有体系的 code 或名称（见下表）；写一个新名称就会成为「自定义体系」，出现在谋略库的筛选里 |
| 出处 | | 篇章、计数等，显示在名称上方 |
| 领域 | | 职场、生活、为人处世、谈判、管理、心态、投资理财、创业 中选，多个用顿号或逗号分开；不填默认「为人处世」 |
| 框架 | | 表达框架 code，最多 4 个，智囊出锦囊时会优先推荐这些框架 |
| 慎用 | | 是 / 否。慎用的谋略智囊只用来帮用户识别和防范，不教用户用它对付别人 |
| 启用 | | 填「否」则导入后不出现在谋略库和锦囊里 |
| ### 原文 | | 经典原句 |
| ### 白话 | ✓ | 一两句讲清楚是什么意思 |
| ### 怎么做 | ✓ | 每行一步，最多 8 步；慎用的谋略写「怎么识别和防范」 |
| ### 怎么说 | ✓ | 一句可以直接说出口的话（会出现在示范朗读里） |
| ### 常见误用 | | 一两句 |

## 二、谋士

文件第一行：`# talktool-advisors`

```markdown
## 谋士：老周
- code: laozhou
- 头像: 周
- 风格: 务实
- 体系: maoxuan, zhanguoce

### 人设
国企老处长，见过各种人事斗争。看问题先看人和关系，再看事；说话直白，爱用“我当年……”举例。
```

| 字段 | 必填 | 说明 |
|---|---|---|
| code | ✓ | 规则同谋略；不能以 `my_` 开头（那是用户的私人谋士） |
| 头像 | | 一个字，不填取名字第一个字 |
| 风格 | | 两个字，如 稳健 / 进取 / 犀利 |
| 体系 | | 擅长的谋略体系，最多 4 个 |
| ### 人设 | ✓ | 会直接写进提示词：身份、看问题的角度、说话风格 |

导入的谋士在 **智囊团配置** 里可以选。

## 三、智囊团

文件第一行：`# talktool-councils`

```markdown
## 智囊团：职场新人团
- code: newbie
- 图标: 新
- 谋士: junshi, laozhou
- 体系: rujia, xiushen
- 领域: 职场
- 启用: 是

### 处理什么问题
刚工作一两年遇到的问题：不敢开口、被安排杂活、和带教的关系。

### 特别要求
多鼓励；建议拆成小步，每一步当天就能做。

### 示例问题
- 带教总让我干杂活怎么办
- 第一次给领导汇报很紧张
```

| 字段 | 必填 | 说明 |
|---|---|---|
| code | ✓ | 小写字母开头，2–21 位；同时是提示词的 key（`council.<code>`） |
| 谋士 | ✓ | 1–4 位已有谋士的 code（内置或已导入） |
| 体系 / 领域 | | 这个团出主意时优先用哪些谋略；不填 = 全库 |
| ### 处理什么问题 | ✓ | 意图识别靠这句话分派问题，写清楚边界 |
| ### 特别要求 | | 会写进这个团的默认提示词 |
| ### 示例问题 | | 最多 5 个，显示在智囊首页 |

新团导入后自动出现在意图识别的选项里，排在「综合团」前面，并自动有一份默认提示词，可以到 **提示词管理** 里修改。

内置谋士 code：junshi（军师）、zhanlue（战略家）、bingjia（兵家）、zongheng（纵横家）、moulue（谋略家）、tanpan（谈判官）、xiansheng（先生）、xinli（心理顾问）、zhixin（知心大姐）、licai（理财顾问）、chuangye（创业导师）。
