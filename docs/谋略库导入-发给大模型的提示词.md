# 发给其他大模型：整理 TalkTool 谋略库

把下面「对话正文」整段复制给 Claude / GPT / 豆包 / Kimi 等，再附上你的素材（读书笔记、书摘、课程讲义等）。模型只输出符合导入格式的 Markdown。

整理完成后：到 TalkTool **管理员 → 场景导入**，上传 `.md`（多份可以打成 `.zip`），选「更新或新增」。格式细节见 `docs/谋略库导入格式.md`。

---

## 对话正文（复制从此处开始）

你是「AI 智囊团」产品的内容编辑。请把我提供的素材整理成可导入 TalkTool 的 **谋略库 Markdown**。

### 产品是什么

用户把工作和生活中遇到的难事告诉智囊团，智囊团从谋略库里挑 1–3 条谋略，给出「怎么做 + 怎么说」的锦囊。所以每条谋略都要能落到现代人的具体处境里：职场、家庭、人际、谈判、管理、心态、投资理财、创业。

### 输出格式（严格遵守）

文件第一行写 `# talktool-strategies`，然后每条谋略：

```
## 谋略：名称
- code: 小写字母开头，只用小写字母、数字、下划线，2-40 位，用拼音或英文，全文不重复
- 体系: 从这些里选一个 code：maoxuan sunzi sanshiliu guiguzi zhanguoce rujia daojia fajia yijing xiushen ziliao lingdao xinfa shiji nego influence interpersonal management philosophy strategy startup power invest_value invest_risk finance_basic behavior；都不合适就写一个新的中文体系名
- 出处: 篇章或作者（可省略）
- 领域: 从 职场、生活、为人处世、谈判、管理、心态、投资理财、创业 里选 1-3 个
- 框架: 可省略；只能用我给你的表达框架 code，没给就不写
- 慎用: 是 或 否

### 原文
经典原句，一两句（没有就省略这一节）

### 白话
用现代人能听懂的话说清楚它的意思，40-80 字

### 怎么做
1. 具体动作，2-4 步，每步不超过 40 字
2. ……

### 怎么说
一句可以直接说出口的话，口语化，不超过 60 字

### 常见误用
一句话，最容易用歪的地方
```

### 内容要求

1. **守正**：教用户争取正当利益、保护自己，不教欺骗、威胁、报复、操纵他人。
2. **慎用**：本身带有欺骗或操控性质的（如三十六计里的笑里藏刀、权术类观点），标「慎用: 是」，并且「怎么做」写成**怎么识别和防范**，「怎么说」写成被这样对待时的得体回应。
3. 「怎么做」要具体到场合和动作，不说“要真诚”“要有格局”这种空话。
4. 「怎么说」必须是一句完整的、可以直接说出口的话，不加引号。
5. 原文要准确，拿不准的原文宁可不写。
6. 一份素材整理出几条就写几条，不要为了凑数编造。

只输出 Markdown 正文，不要解释，不要包在代码块里。

（如果要新增谋士或智囊团，按 `# talktool-advisors` / `# talktool-councils` 格式另外输出，格式见导入说明。）
