# TalkTool 操作手册

产品正式名：**沟通表达演练场**（TalkTool）。用 AI 扮演沟通对手，和你纯语音对练，练完出报告。

- 线上地址：https://talk.aidigitcloud.cn  
- 适用对象：普通学员、管理员  
- 开发/部署说明见仓库根目录 [`README.md`](../README.md)；场景内容批量整理见 [`场景库导入格式.md`](./场景库导入格式.md)

---

## 一、快速上手（学员）

1. 用**邀请码**注册账号（或登录已有账号）。
2. 底部点 **场景**，选分类 → 场景大类 → 一张训练卡片。
3. 看完场景介绍，点 **开始训练**；允许麦克风。
4. AI 先开口 → 你口头回答 → 停顿约 2 秒自动提交（也可再点麦克风结束）。
5. 点 **结束训练** → 看报告；可收藏话术到 **练习本**，或进 **训练记录** 回看。

建议：第一次先选「低压」短场景，戴耳机，安静环境。

---

## 二、账号与登录

| 操作 | 怎么做 |
|---|---|
| 注册 | 登录页切到注册，填用户名、密码、昵称、**邀请码** |
| 带码链接 | 管理员发来的链接打开后，邀请码会自动填上 |
| 登录 | 用户名 + 密码；令牌约 30 天有效 |
| 改昵称 | 我的 → 改昵称 |
| 改密码 | 我的 → 修改密码（原密码 + 新密码两次） |
| 退出 | 我的 → 退出登录 |

说明：

- 目前不支持微信/手机号一键登录。
- 同一网络短时间多次输错密码会暂时锁定，稍后再试。
- 注册前在本机练过的记录，用这台设备注册时会尽量归到新账号。

## 三、底部四个入口

| Tab | 作用 |
|---|---|
| 首页 | 快捷入口：表达框架库、自定义场景、继续练等 |
| 场景 | 按分类浏览全部公共训练 |
| 练习本 | 收藏的话术 / 建议 / 示范稿，可反复听示范与跟读 |
| 我的 | 账号、音色、训练记录、自定义场景、管理后台（管理员） |

## 四、选场景并开始训练

### 4.1 浏览路径

```
场景 Tab → 左侧分类 → 右侧场景大类 → 场景列表里的训练卡片 → 场景介绍 → 开始训练
```

场景介绍页通常会看到：

- 压力等级（低压 / 中压 / 高压）、预计时长、训练方式（纯语音）
- 场景描述（你是谁、对方是谁、要完成什么）
- **推荐表达框架**（步骤 + 本场景示例）
- **常见误区**
- **跟读示范**（可选：先听示范稿再跟读打分）
- **开始训练**

### 4.2 训练中怎么说

1. AI 讲话时请听完，不要抢话。
2. 提示可以说话后再开口；页面有音量条。
3. 说完停顿约 **2 秒**会自动提交；也可再点麦克风按钮结束本句。
4. 底部可打开 **框架提示** 小抄（只看步骤，不暂停训练）。
5. 想结束时点 **结束训练**。

注意：

- 全程**只语音**，没有打字框。
- 几乎没人声的短录音不会送识别（避免误触浪费次数）。
- 单场发言轮数有上限；每天可开的训练次数也有限额。
- 中途退出且一句没说 → 记为「主动放弃」；时间太短或没有效发言 →「时长过短」，可能没有完整报告。

### 4.3 训练报告

结束后进入报告页（报告可能在后台生成，页面会自动刷新；失败可点重新生成）。

常见内容：

- 总分与四维（逻辑表达 / 语言组织 / 应变能力 / 情绪管理）
- 与同场景**上次**对比（若有）
- 亮点、改进建议、详细点评
- **表达数据**：语速、反应时间、口头禅、长停顿（由录音计算）
- **逐句复盘**：更好说法 + 点拨；可听示范、跟读、收藏
- **对照表达框架**：是否用上推荐框架、误区提醒

报告结论仅反映**这一次**练习，仅供参考。

### 4.4 训练记录

我的 → **训练记录**（或相关入口）：按全部 / 本周 / 本月筛选，点进可再看报告。

## 五、跟读与示范

| 入口 | 做什么 |
|---|---|
| 场景介绍 → 跟读示范 | AI 先写示范稿（会缓存），听示范 → 跟读 → 发音分 |
| 报告逐句复盘 / 框架示例 / 练习本 | 「听示范」「跟读」；跟读可显示分数与「识别到」的文本 |
| 收藏 | 「收藏到练习本」后，在练习本里反复练并记最高分 |

听示范若觉得偏轻：检查手机音量、勿开静音；账号可在「我的 → 音色设置」切换男女声并试听。

## 六、表达框架库

入口：首页 **表达框架库**，或场景介绍里的推荐框架。

- 按分类筛选、搜索
- 详情含：步骤、适用场合、示例（可听/跟读/收藏）、误区、技巧
- 「去这些场景里练」：跳到用了该框架的训练

训练中可随时打开框架提示对照步骤。

---

## 七、自定义场景

入口：首页或 我的 → **我的自定义场景**。

1. 用几句话描述真实情境（对方是谁、卡在哪）。
2. 选择对方态度 / 压力倾向。
3. 提交后 AI 生成角色、背景、开场白，并尽量挂上推荐框架与误区。
4. 生成后可立刻开练；**仅本人可见**。
5. 数量有上限（默认约 30 个），不需要的可删除。

自定义场景不会出现在公共「场景」分类列表里。

## 八、音色与设备

| 设置 | 位置 |
|---|---|
| AI 男声 / 女声 | 我的 → 音色设置 → 试听 |
| 麦克风权限 | 系统设置里允许浏览器/App 使用麦克风 |
| 服务状态 | 我的页底部「服务状态」（检测后端是否正常） |

建议使用 Chrome / 系统浏览器打开 H5；手机建议 HTTPS 环境（生产站已是）。微信内置浏览器若麦克风异常，可改用系统浏览器打开同一链接。

## 九、管理员操作

管理员账号在「我的」会多一项：**管理后台**。

### 9.1 邀请码

1. 管理后台 → **邀请码**。
2. 填数量、每个可用次数、有效天数（0 = 永久）、备注。
3. 点生成 → 复制单个码，或「全部复制」；H5 还可复制**注册链接**。
4. 可对仍有效的码执行 **停用**（已注册用户不受影响）。

命令行（服务器上，可选）：

```bash
cd /opt/talktool/backend
.venv/bin/python -m app.admin invite 5 1 30    # 5 个码，各用 1 次，30 天
.venv/bin/python -m app.admin users
.venv/bin/python -m app.admin create-admin 用户名 密码
```

### 9.2 用户

管理后台 → **用户**：

- 查看训练次数、最近登录 / 训练时间、邀请码来源
- **停用**：立即下线且无法再登录；可再 **启用**
- **重置密码**：生成一次性临时密码（只显示一次，请复制发给对方）
- 不能停用/重置自己的管理员账号（界面会限制）

### 9.3 场景库导入（更新内容）

管理后台 → **场景导入**。

1. 用其他大模型按 [`场景库导入-发给大模型的提示词.md`](./场景库导入-发给大模型的提示词.md) 整理出 `.md`，或多个 md 打成 `.zip`。
2. 格式说明见 [`场景库导入格式.md`](./场景库导入格式.md)；样例：[`examples/catalog-sample.md`](./examples/catalog-sample.md)。
3. 选择模式：
   - **更新或新增**：同名分类 / 场景 / 训练 / 框架 → 覆盖内容；没有的 → 新增。**不会删除**库里多出来的旧条目。
   - **仅新增**：已存在则跳过。
4. 点「选择文件并导入」，看结果摘要（框架/训练各新增、更新多少）。

匹配规则简述：分类按名称；场景按「分类+标题」；训练按「场景+标题」（仅公共场景）；框架按 `code`。

## 十、常见问题

| 现象 | 处理 |
|---|---|
| 注册提示邀请码无效 | 码用完、过期或已停用；找管理员再发 |
| 点开始训练没声音 / 没反应 | 检查麦克风权限、是否 Mock/网关异常（我的 → 服务状态） |
| 识别不准或跟读乱码 | 靠近麦克风、减少噪音；跟读乱码若仍出现请反馈版本（讯飞解析已修过） |
| 示范音太小 | 调高系统音量；我的里试听音色；仍小再反馈 |
| 报告一直转圈 | 等十几秒自动刷新；失败点「重新生成」 |
| 提示今日次数用完 | 对练 / 跟读 / 示范 / 自定义等有日限额，次日再试 |
| 想改公共场景文案 | 管理员用「场景导入」upsert；勿直接改生产库 |
