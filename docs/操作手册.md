# TalkTool 操作手册

产品正式名：**沟通表达演练场**（TalkTool）。用 AI 扮演沟通对手，和你纯语音对练，练完出报告。

- 线上地址：https://talk.aidigitcloud.cn  
- 适用对象：普通学员、管理员  
- 开发/部署说明见仓库根目录 [`README.md`](../README.md)；场景内容批量整理见 [`场景库导入格式.md`](./场景库导入格式.md)

---

## 一、快速上手（学员）

1. 用**邀请码**注册账号（或登录已有账号）。
2. 底部点 **场景**，选分类 → 场景大类 → 一张训练卡片。
3. 看完场景介绍，点 **开始训练**；允许麦克风。
4. AI 先开口 → 你口头回答 → 停顿约 2 秒自动提交（也可再点麦克风结束）。
5. 点 **结束训练** → 看报告；可收藏话术到 **练习本**，或进 **训练记录** 回看。

建议：第一次先选「低压」短场景，戴耳机，安静环境。

## 二、账号与登录

| 操作 | 怎么做 |
|---|---|
| 注册 | 登录页切到注册，填用户名、密码、昵称、**邀请码** |
| 带码链接 | 管理员发来的链接打开后，邀请码会自动填上 |
| 登录 | 用户名 + 密码；令牌约 30 天有效 |
| 改昵称 | 我的 → 改昵称 |
| 改密码 | 我的 → 修改密码（原密码 + 新密码两次） |
| 退出 | 我的 → 退出登录 |

说明：

- 目前不支持微信/手机号一键登录。
- 同一网络短时间多次输错密码会暂时锁定，稍后再试。
- 注册前在本机练过的记录，用这台设备注册时会尽量归到新账号。

## 四、选场景并开始训练

### 4.1 浏览路径

```
场景 Tab → 左侧分类 → 右侧场景大类 → 场景列表里的训练卡片 → 场景介绍 → 开始训练
```

场景介绍页通常会看到：

- 压力等级（低压 / 中压 / 高压）、预计时长、训练方式（纯语音）
- 场景描述（你是谁、对方是谁、要完成什么）
- **推荐表达框架**（步骤 + 本场景示例）
- **常见误区**
- **跟读示范**（可选：先听示范稿再跟读打分）
- **开始训练**

### 4.2 训练中怎么说

1. AI 讲话时请听完，不要抢话。
2. 提示可以说话后再开口；页面有音量条。
3. 说完停顿约 **2 秒**会自动提交；也可再点麦克风按钮结束本句。
4. 底部可打开 **框架提示** 小抄（只看步骤，不暂停训练）。
5. 想结束时点 **结束训练**。

注意：

- 全程**只语音**，没有打字框。
- 几乎没人声的短录音不会送识别（避免误触浪费次数）。
- 单场发言轮数有上限；每天可开的训练次数也有限额。
- 中途退出且一句没说 → 记为「主动放弃」；时间太短或没有效发言 →「时长过短」，可能没有完整报告。

### 4.3 训练报告

结束后进入报告页（报告可能在后台生成，页面会自动刷新；失败可点重新生成）。

常见内容：

- 总分与四维（逻辑表达 / 语言组织 / 应变能力 / 情绪管理）
- 与同场景**上次**对比（若有）
- 亮点、改进建议、详细点评
- **表达数据**：语速、反应时间、口头禅、长停顿（由录音计算）
- **逐句复盘**：更好说法 + 点拨；可听示范、跟读、收藏
- **对照表达框架**：是否用上推荐框架、误区提醒

报告结论仅反映**这一次**练习，仅供参考。

### 4.4 训练记录

我的 → **训练记录**（或相关入口）：按全部 / 本周 / 本月筛选，点进可再看报告。

## 五、跟读与示范

| 入口 | 做什么 |
|---|---|
| 场景介绍 → 跟读示范 | AI 先写示范稿（会缓存），听示范 → 跟读 → 发音分 |
| 报告逐句复盘 / 框架示例 / 练习本 | 「听示范」「跟读」；跟读可显示分数与「识别到」的文本 |
| 收藏 | 「收藏到练习本」后，在练习本里反复练并记最高分 |

听示范若觉得偏轻：检查手机音量、勿开静音；账号可在「我的 → 音色设置」切换男女声并试听。

## 六、表达框架库

入口：首页 **表达框架库**，或场景介绍里的推荐框架。

- 按分类筛选、搜索
- 详情含：步骤、适用场合、示例（可听/跟读/收藏）、误区、技巧
- 「去这些场景里练」：跳到用了该框架的训练

训练中可随时打开框架提示对照步骤。

## 七、自定义场景

入口：首页或 我的 → **我的自定义场景**。

1. 用几句话描述真实情境（对方是谁、卡在哪）。
2. 选择对方态度 / 压力倾向。
3. 提交后 AI 生成角色、背景、开场白，并尽量挂上推荐框架与误区。
4. 生成后可立刻开练；**仅本人可见**。
5. 数量有上限（默认约 30 个），不需要的可删除。

自定义场景不会出现在公共「场景」分类列表里。

## 七点五、AI 智囊团

入口：底部 **智囊** Tab（首页也有「问智囊团」）。

1. **说情况**：在输入框里描述，或点麦克风说话（识别成文字后可以修改再发）。也可以先点某个智囊团，直接交给它。设了私人谋士的话，输入框下面可以点选请谁列席（最多 2 位）。
2. **智囊分派**：系统判断问题类型，交给对应的智囊团（向上与晋升、团队与同事、谈判与商务、家庭与亲密、社交与人情、成长与抉择、投资理财、创业、综合）。信息不够时会先问 1–3 个问题，点选项即可，也可以「跳过，直接出主意」。
3. **拿锦囊**：约 20–40 秒。锦囊里有一句话判断、局势研判、目标与底线、用哪几计、**怎么做**（可勾选的行动清单，每项可点「⏰ 设提醒」选日期）、**怎么说**（关键话术，可听示范、跟读、收藏）、风险预案、不要做、各位谋士的看法。点谋略名可看原文和白话。锦囊底部可以评价「有用 / 没用」，说没用时可以写一句原因，帮我们改进。
4. **继续问 / 换个团**：对锦囊有疑问直接问；想换思路点右上角「换个团」。锦囊每次修改都会保留历史版本。
5. **圆桌会议**：想听不同意见，点锦囊卡片上的「开圆桌」，或在输入框上方选「圆桌辩论」并写下想争论的焦点（如“要不要当面摊牌”，可不填）。几位谋士会各自亮明主张、互相反驳，最后由军师裁决；觉得裁决有道理，点「按裁决调整锦囊」。
6. **去演练**：锦囊页底部「去演练」，AI 按对方的性格扮演，练完的报告会对照锦囊点评。
7. **回来复盘**：照做之后，在对话里切到「回来复盘」，说说结果，智囊帮你调整下一步。勾选的行动和演练结果会记进这件事的「事件线」。

**该跟进了**：出锦囊后，智囊会按事情的紧急程度约一个跟进时间（紧急 1 天、一般 3 天、不急 7 天）；行动设了提醒的，到日子也会提醒；行动全部打勾后会马上请你回来复盘。到期的事出现在智囊首页最上面的「该跟进了」，底栏「智囊」会有数字角标。可以点「回来复盘」「过两天再提醒」或「不用提醒了」。提醒只在应用里显示，不会推送消息。

**我的私人谋士**：智囊首页 →「我的私人谋士」。可以把信任的前辈、朋友、家人，或者你想象中的高人设成谋士：写名字、人设（他是谁、看问题的角度、说话风格）、风格和擅长的谋略，最多 6 位，也可以从模板改。问计时在输入框下点选，或在对话页顶部点「+谋士」请他们列席；列席的谋士会参与出锦囊和圆桌会议。只有你自己能看到。

**谋略库**：智囊首页 → 谋略库，400 多条，可按体系（毛选、孙子兵法、三十六计、鬼谷子、史记、心学、管理、谈判、行为金融……）和领域筛选、搜索。标「慎用」的计策只用于识别和防范别人。

**智囊记得的（长期记忆）**：我的 → 智囊记得的。分「我的档案 / 人物卡 / 事件线 / 训练画像」。每条可改、可删；人物卡可改名、加别名、合并；卡片「管理」里可以「整理」（合并重复、去掉过时的，置顶的不动）；可以随时暂停记忆或清空。记忆默认开启，只有你自己能看到。也可以在对话里说「记住……」「忘掉……」。条目多了智囊会定期自动整理；30 天没有进展的事会标为「搁置」，不再自动带进问计，有新进展时自动恢复。

**训练报告的长期对比**：练过几次之后，报告里会多一张「和你的长期水平比」：每个维度和你之前的平均分比，口头禅和之前比是在改善还是老问题；AI 点评也会点出这些。

> 智囊的建议仅供参考；投资理财只讲原则和风险，不推荐具体产品；涉及人身安全、自伤、违法的问题，智囊会给出安全提醒而不是计策。

## 九、管理员操作

管理员账号在「我的」会多一项：**管理后台**。

### 9.1 邀请码

1. 管理后台 → **邀请码**。
2. 填数量、每个可用次数、有效天数（0 = 永久）、备注。
3. 点生成 → 复制单个码，或「全部复制」；H5 还可复制**注册链接**。
4. 可对仍有效的码执行 **停用**（已注册用户不受影响）。

命令行（服务器上，可选）：

```bash
cd /opt/talktool/backend
.venv/bin/python -m app.admin invite 5 1 30    # 5 个码，各用 1 次，30 天
.venv/bin/python -m app.admin users
.venv/bin/python -m app.admin create-admin 用户名 密码
```

### 9.2 用户

管理后台 → **用户**：

- 查看训练次数、最近登录 / 训练时间、邀请码来源
- **停用**：立即下线且无法再登录；可再 **启用**
- **重置密码**：生成一次性临时密码（只显示一次，请复制发给对方）
- 不能停用/重置自己的管理员账号（界面会限制）

### 9.3 场景库导入（更新内容）

管理后台 → **场景导入**。

1. 用其他大模型按 [`场景库导入-发给大模型的提示词.md`](./场景库导入-发给大模型的提示词.md) 整理出 `.md`，或多个 md 打成 `.zip`。
2. 格式说明见 [`场景库导入格式.md`](./场景库导入格式.md)；样例：[`examples/catalog-sample.md`](./examples/catalog-sample.md)。
3. 选择模式：
   - **更新或新增**：同名分类 / 场景 / 训练 / 框架 → 覆盖内容；没有的 → 新增。**不会删除**库里多出来的旧条目。
   - **仅新增**：已存在则跳过。
4. 点「选择文件并导入」，看结果摘要（框架/训练各新增、更新多少）。

匹配规则简述：分类按名称；场景按「分类+标题」；训练按「场景+标题」（仅公共场景）；框架按 `code`。

### 9.4 智囊提示词与智囊团

入口：我的 → **智囊提示词管理** / **智囊团配置**（管理后台页顶部也有入口）。

- **提示词**：按工作流列出每一步（意图识别、追问、安全回复、各智囊团出谋、追问与修改锦囊、圆桌会议、记忆提取、记忆整理）。版本历史里会显示每个版本出的锦囊被用户评为「有用」的比例。改完 → 保存草稿 → 输入一个测试问题「试运行」（不会产生问计和记忆）→ 满意再发布。版本历史里可以回滚，也可以恢复默认。必填变量（深色）不能删。
- **智囊团**：可改名称、处理范围（意图识别靠这句话分派）、谋士、谋略子库、特别要求、示例问题，可停用；也可以新建一个团，它会自动出现在意图识别的选项里，提示词默认用通用模板 + 你写的特别要求。
- **问计效果统计**：管理后台顶部「问计效果统计 ›」。可选近 7 / 30 / 90 天：总的问计、锦囊、有用率、去演练、回来复盘、行动完成；按智囊团对比；按提示词版本对比有用率（评价少于 10 条时仅供参考，点一行可以直接去改那份提示词）；最下面是用户写的「没用」原因。只统计数量和比例，看不到用户问了什么。
- **导入谋略 / 谋士 / 智囊团**：和场景库同一个入口（管理后台 → 场景导入），上传 Markdown。格式见 `docs/谋略库导入格式.md`；手上有读书笔记、讲义，可以把 `docs/谋略库导入-发给大模型的提示词.md` 连同素材发给大模型整理。按 code 更新或新增；导入的内容以后程序升级不会覆盖；有问题的字段会在导入结果里提示。

## 十、常见问题

| 现象 | 处理 |
|---|---|
| 注册提示邀请码无效 | 码用完、过期或已停用；找管理员再发 |
| 点开始训练没声音 / 没反应 | 检查麦克风权限、是否 Mock/网关异常（我的 → 服务状态） |
| 识别不准或跟读乱码 | 靠近麦克风、减少噪音；跟读乱码若仍出现请反馈版本（讯飞解析已修过） |
| 示范音太小 | 调高系统音量；我的里试听音色；仍小再反馈 |
| 报告一直转圈 | 等十几秒自动刷新；失败点「重新生成」 |
| 提示今日次数用完 | 对练 / 跟读 / 示范 / 自定义等有日限额，次日再试 |
| 想改公共场景文案 | 管理员用「场景导入」upsert；勿直接改生产库 |

## 断线恢复与系统提醒

- 问计、出锦囊、追问、复盘和圆桌提交后在服务器后台执行。页面显示当前阶段，可以离开后回来查看；网络恢复或刷新页面会找回原任务，不必重复点击。
- 同一问计同时只处理一个生成任务。服务重启时，已保存的结果会恢复；尚未保存的任务会明确显示中断，用户确认后重试。
- 对话打开时每 3 秒刷新，其他设备新增的消息和列席谋士会同步，本地未发送草稿不被覆盖。PC 端 Enter 发送，Shift+Enter 换行，输入法选字时不会发送。
- 在「我的 → 到期提醒」为当前设备开启系统提醒。浏览器需要允许通知；iPhone/iPad 需将网页添加到主屏幕后从该入口打开。服务器每分钟检查到期事项，通过 Web Push 发送，即使网页已关闭也可接收（取决于浏览器、系统权限与推送服务网络）。通知只显示通用提醒，不展示案情或人物名称。
- 关闭提醒或退出账号会取消当前浏览器订阅。每台设备独立设置；同一浏览器切换账号后重新开启提醒即可绑定当前账号。
- 原生 App 使用已同步事项的本地通知；跨设备新增或修改的事项需打开 App 同步。它不等同于厂商远程推送。正式安装包需有效 DCloud appid 和对应原生模块，当前仓库未提供 appid，不能用 H5 发布代替 APK 更新。
- 浏览器录音在结束、离页和切后台时释放麦克风。原生 App 因当前运行时不支持录音分帧回调，录完后再次点击结束；语音输入最长 90 秒。训练切后台会暂停，返回后点击麦克风继续。

部署会自动建立任务与通知表。Web Push 私钥自动生成在 `backend/data/webpush-private.pem`，部署时保留，不提交 Git；备份数据库时同时备份该文件。可通过 `WEBPUSH_SUBJECT` 设置 VAPID 联系地址，默认使用本站 HTTPS 地址。

回归测试（在 `backend/` 下执行）：`for test in tests/test_*.py; do .venv/bin/python "$test" || break; done`。
